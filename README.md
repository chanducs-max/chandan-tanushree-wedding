# Chandan & Thanushree — Wedding Invitation Website

A custom, mobile-first wedding invitation inspired by the supplied invitation card, but with a different visual design from the reference website.

## Included
- Responsive mobile/desktop design
- Animated scroll reveals
- Countdown to 21 September 2026
- Wedding location button using the QR-code destination from the supplied card
- Original invitation card image
- Add-to-calendar `.ics` generation
- Native share button on supported phones
- Family/contact section

## Run locally
Open `index.html` in a browser.

For best results on a phone, publish the folder through GitHub Pages.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. GitHub will provide the public invitation URL.

## Easy changes
- Wedding time: edit `weddingDate` in `script.js`.
- Venue name/address: edit the Wedding Ceremony section in `index.html`.
- Phone numbers: edit the contact links in `index.html`.
- Colors/fonts/layout: edit `style.css`.
